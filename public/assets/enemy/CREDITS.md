# 敵キャラクターのアセット

## monster.glb
- 制作: プロジェクトメンバー(生成AIツールで作成)
- 元ファイル: fantasy+monster+3d+model.glb (14.9MB / 501,094三角形)
- 最適化: gltf-transform で以下を実施し、655KB / 16,952三角形にした。
    1. weld        … 重複頂点の統合
    2. simplify    … ポリゴン削減 (--ratio 0.008 --error 0.02)
    3. resize      … テクスチャを 512x512 に縮小
- 削減率: 三角形 約1/30、ファイルサイズ 約1/23

NOTE: 16,952三角形が現状の下限。UVの継ぎ目が頂点分割として保護されるため、
      これ以上減らすには Blender 等での再UV展開が必要。
      敵は同時に複数体出るので、さらに軽くしたい場合はここを検討する。

NOTE: 既存作品(ファイナルファンタジー等)のキャラクターを模したモデルは
      著作権の問題があるため使用しないこと。
